# Private Memory Book

Private Memory Book is a local-first Windows app for turning photos, videos, audio, and writing into an interactive memory album.

Your album content stays in the folder you choose on your own computer. The app does not upload your photos, videos, audio, writing, or album folders.

## Highlights

- Organize memories by year, month, and day
- Add text, photos, videos, and audio
- Browse memories as an interactive book or retro television
- Choose from multiple visual themes
- Export a self-contained offline album
- Back up and move complete project folders
- Use Simplified Chinese, English, Traditional Chinese, Japanese, German, or French

## System requirements

- Windows 10 or Windows 11, 64-bit
- Sufficient local storage for your own media files

Starting with v0.14.0, the app can check GitHub Releases for software updates. Update checks send no album content. Release assets published in this repository are used only to deliver application updates.

Users on v0.13.3 or earlier must install v0.14.0 manually once. Later releases can be downloaded and installed from inside the app.
